Exposure and answers

How many of mine hit this type hard?

Left of the axis is defence, what this type does to you: red for the slots that take 2× or more, blue for the slots it cannot touch at all. Right is answers, the slots whose best entered move lands 2× or more. Every block is one Pokémon, so bar length is a straight count.

Net is a raw count of answers plus immunities minus exposures, so a 4× liability weighs the same as a 2× and an answer that folds in return still counts in full. A slot that both walls a type and hits it hard counts once on each side. Abilities are not modelled.
